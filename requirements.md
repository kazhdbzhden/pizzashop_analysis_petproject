# Требования

**Функциональные:**

- **Бизнес**: сайт пиццерии должен увеличить количество клиентов;

- **Пользователей**: пользователь хочет иметь возможность заказать пиццу
  онлайн;

- **Системные**: система должна предоставлять информацию о статусе
  заказа в реальном времени.

**Нефункциональные:**

- **Атрибут качества - безопасность:** система должна хранить личные
  данные пользователей в зашифрованном виде;

- **Локализация:** система должна принимать оплату с карт Российской
  Федерации в рублях, Республики Казахстан в тенге, республики
  Кыргызстан в сомах.

- **Реализация:** сайт должен корректно отображаться на десктопных
  (браузеры яндекс, opera, google, mozilla, explorer) и мобильных
  устройствах (ios, android).
