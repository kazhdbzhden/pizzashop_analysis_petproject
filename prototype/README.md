## Прототип

Разработан интерактивный прототип пользовательского интерфейса
системы онлайн-заказа пиццы.

Прототип включает сценарии:

- авторизация;
- просмотр каталога;
- просмотр страницы товара;
- просмотр корзины;
- оформление заказа;
- страница подтверждения заказа;
