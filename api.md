Набор методов:

**Пользователь**

  ----------------- -------------------- ------------------------------------
  **HTTP-запрос**   **Конечная точка**   **Действие**

  GET               /users/\<UserID\>    Получить информацию о личных данных
                                         пользователя \<UserID\>

  POST              /users               Создать аккаунт

  PUT               /users/\<UserID      Изменить личные данные в аккаунте
                                         \<UserID\>

  DELETE            /users/\<UserID      Удалить аккаунт \<UserID\>
  ----------------- -------------------- ------------------------------------
